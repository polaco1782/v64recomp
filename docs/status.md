# Game support

Desktop builds now use GLES. RT64 results below record validation of earlier builds. See [desktop GLES coverage](desktop-coverage.md) for renderer-specific results.

The experimental [WebAssembly target](webassembly.md) covers the game catalog and automatically loads the profile ROM alongside the WebAssembly module. See the browser validation notes for tested scenes and configurations.

These are the established port milestones, not new full-game acceptance claims.

- **Bad Apple!! demo**: Build-time download of a pinned external ROM; no ROM is bundled. Windows Debug/Release builds and rendered playback pass. The MMIO store bypass and recurring audio starvation are fixed. A 60-second Release trace had one startup underrun and none afterward; a 30-second Debug trace had zero underruns, exact ROM PCM output and a verified rendered frame. Neither run reset the audio queue. Full-loop, listening and Linux acceptance remain unverified. See the [demo notes](../games/bad-apple/README.md).

- **007: The World Is Not Enough USA revision 0**: Experimental partial port. Original startup, guest threads, VI/AI events, cartridge DMA and fingerprinted MusyX v1 task execution are integrated. Title/menu rendering, playable missions, input acceptance, audible accuracy and save/reload remain unverified. Unconverted module calls fail explicitly. See the [port notes](../games/twine-us/README.md).

- **Banjo-Kazooie US revision 0**: Experimental partial port. Original cartridge DMA/RareZip loading, verified resident/level images and NAudio synthesis run. The Nintendo/Rareware logos render; the user confirmed working audio. Missing CIC-6103 boot state caused the projection check to force clipping planes to 750/1250; restoring the ROM-verified IPL3 values fixes the clipped sky/background. Presentation retains the original steady 30 Hz rate, and idle detection begins after thread initialization. The port supports WASD movement, mouse camera control and adjustable gameplay FOV. Full progression and save/reload remain unverified. See the [port notes](../games/banjo-kazooie-us/README.md).

- **1080 Snowboarding JU revision 0**: Earlier Debug and Release runs render the intro/title and navigate Match Race into Select Rider, completing the 3,000-frame first-menu replay. The November 7 missing `osSpTaskYielded` native binding is fixed and both builds pass; current replays stop at a separate scene-image mismatch at `0x803f0c2c`, with Select Rider captured in Debug. Original USO loading, ROM-declared symbol discovery, checked scene overlays/relocations, F3DEX graphics and NEAD audio task execution are integrated. Player-controlled riding, later mode transitions, audible accuracy and gameplay save/reload remain unvalidated. Standard OS signatures live in the shared JSON catalog. See the [port notes](../games/1080-us/README.md) and [handoff](../games/1080-us/RESUME.md).

- **Resident Evil 2 US header revision 1**: Experimental bring-up. Original main-image and overlay decompression run with full decoded-image verification. Desktop GLES3 renders the opening movie and reaches the title menu. Some earlier startup frames show corrupted pixels. Start skips the movie. MusyX v1 synthesis and native video resize/conversion are integrated; gameplay, audible audio and save acceptance remain in progress. See the [port notes](../games/re2-us-v1/README.md).

- **Turok: Dinosaur Hunter US v1.2**: Experimental partial conversion with original startup, main menu and first-person gameplay. Debug and Release build; earlier RT64 replays exercised input, firing, weapon selection, death/respawn and pause/resume with ABI1 PCM synthesis. Starting-camera fog/clipping was traced to unstable RT64 projection decomposition and corrected; the user confirmed the fix. The GLES path runs the checked L3DEX 1.00 program for the automap. Default WASD/mouse and keypad FOV controls now have ROM-bound source integration, including CPU visibility; these additions await Debug/Release builds and user gameplay tests. Full-game progression, save/reload and listening quality remain unverified. See the [port notes](../games/turok-us-v12/README.md).

- **Turok 2: Seeds of Evil US 1.0** reached playable Port of Adia in earlier RT64 builds. The original VM streamed the level, the Acclaim adapter rendered the first-person weapon and HUD, and live input exercised WASD, mouse-look and pause. Later levels and campaign save/reload remain untested. [Port notes](../games/turok2-us/README.md)

- **Turok 3: Shadow of Oblivion US** reached the retail title menu, character selection and Chapter 1, The Breach, in earlier desktop RT64 builds. Debug and Release gameplay verified four-way WASD movement, mouse-look and horizontal FOV adjustment from 83.7° to 123.7° and back. Later chapters remain unverified. [Port notes](../games/turok3-us/README.md)

- **Super Mario 64 US**: Working gameplay baseline, with Castle Grounds movement/jumping and the castle lobby transition previously validated. Broader courses, ending and prolonged runs still need validation.
- **GoldenEye 007 US**: Original startup, menus and playable Dam. Keypad FOV original..140 degrees, native dual-stick movement/look and CPU/GPU-consistent widescreen. Shared combat has a ROM-checked native selector in `ai.c`, with distance/visibility-based attacks, sprint pursuit, bounded evasion, stronger weapon/impact/explosion hearing and occasional idle bursts at ordinary scenery. Nearby scientists draw a TT33 and attack; Dr. Doak stays friendly. Blast size/radius is tripled with the original active duration and fade timing. Linux Debug/Release builds and sanitizer scenarios passed for the preceding revision; the latest sound, scientist and explosion changes are unbuilt and untested at the user's request. Combat balance and mission regression still require playtesting. Earlier Steam Deck builds and a live Dam virtual gamepad/rendering check passed. Physical Deck controls, broader widescreen transitions and the reported Dam performance drop still need acceptance/investigation. CPU inventory is partial and remaining unsupported functions fail explicitly; full-game progression remains unverified. See the [game notes](../games/goldeneye-us/README.md).
- **Shadow Man US**: Original startup, audio, Controller Pak, menus and rendered level progression. Framebuffer selection and checked menu/animation/collision callbacks are repaired; movement has been exercised. Loading/HUD grain and later-level coverage remain unverified; this is not a completed game port.
- **Doom 64 US revision 0** reached Staging Area in both RT64 and GLES2 replays. A new-game replay creates a Controller Pak note, enters the level, moves, collects the shotgun, cycles both automaps and pauses. A second run recognized the existing note. The cartridge WESS engine produces stereo PCM through the ABI1 backend. Later levels, campaign save/reload and listening quality remain unverified. [Port notes](../games/doom64-us/README.md)
- **Quake 64 US**: Original menu and playable first level, with movement, turning and shotgun firing previously observed. Default [WASD/mouse and keypad FOV](../games/quake-us/controller.md) have ROM discovery/translation evidence and a passing MSVC Debug build; horizontal FOV ranges from original 90 to 140 degrees with matching CPU clip planes. No standalone tests were added. Release has not been rebuilt and the game has not been launched with these changes. Adapter gameplay acceptance, full-game stability and saves remain unverified.
- **Quake II US revision 0**: Expansion Pak enabled with 8 MiB RDRAM. Debug and Release build; a bounded Debug replay reaches Strogg Outpost with first-person rendering, controller input and nonzero standard NAudio output. The user confirmed that the game runs well and requested no further testing. The single-player mouse-look/WASD adapter has ROM verification and Debug/Release build coverage; the user confirmed it works well in gameplay. Full-game progression, save/reload and sustained audio quality remain unverified. See the [port notes](../games/quake2-us/README.md) and [controller findings](../games/quake2-us/controller.md).
- **Duke Nukem 64 US**: Earlier RT64 builds reached the original menus and first level with ABI1 audio and live input. Default single-player WASD/mouse has ROM verification and earlier Debug/Release builds. Horizontal FOV now uses keypad `+`/`-`, original..140 degrees. The previous implementation has translated CPU/GPU projection evidence. The reported sprite-size mismatch at FOV 110 is corrected with world billboard focal scaling; the user confirmed the input and corrected FOV work well in game. The Deck dual-stick adapter builds in Debug/Release and passes ROM-backed progressive movement/look checks; physical Deck gameplay acceptance is pending. Full-game progression remains unverified. See the [controller guide](../games/duke-us/controller.md), [FOV notes](../games/duke-us/README.md#field-of-view) and [investigation guide](field-of-view.md).
- **Duke Nukem: Zero Hour US revision 0**: Original boot, threads, support-code DMA, ABI1 audio tasks, controller polling and visible copyright/logo screens run in Debug. Title/menu and gameplay bring-up are in progress. See the [port notes](../games/duke-zero-hour-us/README.md).
- **Rayman 2 US revision 0**: Release completes a 1,200-presentation desktop run through the title and rendered language selection; a later bounded Debug replay reaches the rendered opening sequence. WASD, native mouse camera controls and keypad FOV now have ROM-bound adapters; gameplay acceptance of these controls/FOV, progression and save/reload remain unverified. See the [port notes](../games/rayman2-us/README.md).
- **Nightmare Creatures US**: Original title, menus, character selection and playable Chelsea with graphics, ABI1 audio and live input. The captured out-of-range vertex DMA now reads zeroes through the shared RSP runtime and completes in GLES2 Debug and Release. Mouse steering/WASD with native dodges, combat and inventory selection has static ROM verification and Debug/Release build coverage; adapter gameplay acceptance remains for user testing. Full-game progression remains unverified. See [controller findings](../games/nightmare-us/controller.md).
- **Hexen US**: Debug and Release reach the title/class menus and the first level; fighter movement, combat, damage and death have been exercised in bounded desktop runs. Audio produces PCM. The single-player mouse/WASD adapter passes ROM verification and earlier Debug/Release builds; live adapter acceptance remains for the user's test. Horizontal FOV uses keypad `+`/`-`, original..140 degrees. Live changes now update the cached world projection as well as CPU visibility tables; this correction passes Linux Debug/Release builds and ROM/translation verification. The user confirmed the live FOV controls work after rebuilding. Full-range visibility, combined F7 behavior, other classes, hub progression, save/reload and listening quality remain unverified. See the [port notes](../games/hexen-us/README.md) and [controller findings](../games/hexen-us/controller.md).
- **Ocarina of Time US V1.2**: Original title, file select, name entry and new-game opening with verified decompressed code and 469 relocatable overlays. Zelda NEAD audio and recompiled RSP JPEG decoding are supported; Link's house background has been checked in the opening. Default [WASD/third-person mouse controls](../games/oot-us-v12/controller.md) and optional horizontal FOV (keypad `+`/`-`, original..140 degrees) have ROM-bound evidence. Earlier implementations passed MSVC Debug/Release builds; gameplay acceptance remains pending. Inventory and full-game validation remain incomplete.

- **Majora’s Mask US** ran in earlier desktop RT64 builds with the Expansion Pak. Debug replays created and reloaded a FlashRAM file, played the opening with stereo audio and moved Link through the forest. The generator checks the main executable and 617 overlays. Desktop Debug and Release tests exercised WASD, camera orbit and widening and restoring the forest view. Full-game progression is untested. [Port notes](../games/mm-us/README.md)
- **Perfect Dark US V1.1**: Original startup, agent creation, EEPROM saving, menus and first-person Carrington Institute rendering with NAudio/MP3 audio. Live input and the user-tested mission transition work. CPU inventory is partial; an intermittent ADPCM decoder trap, broader regressions and full-game progression remain unverified.

- **Conker's Bad Fur Day US revision 0**: Debug executable builds and runs original startup, guest threads, paged code, cartridge asset loads, controller polling and scene initialization. The Nintendo logo and 3D N64-logo intro render using the verified custom graphics adapter, and NAudio CBFD tasks produce nonzero PCM. The five-second replay exits successfully; longer intro execution is in progress. Intro audio has been heard on the desktop. Title/gameplay, lighting accuracy and save persistence remain unverified. Remaining CPU paths fail at explicit conversion boundaries. See the [port notes](../games/conker-us/README.md) and [resume handoff](../games/conker-us/RESUME.md).
